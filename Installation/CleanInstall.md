# 🧼 Clean Install Guide — Cyberpunk 2077

This guide explains how to **reset your modded Cyberpunk 2077 directory back to a clean state**.  
Use this when diagnosing issues such as:

- Crashes  
- Redscript errors  
- Mod conflicts  
- Suspected broken installs  
- Problems after updating the collection  

A clean install helps determine whether the issue is caused by the **game**, **Vortex**, or the **collection**.

---

## ♦ Step 1 — Check Your Vortex Cyberpunk 2077 Settings

Before doing anything, make sure your Vortex Cyberpunk extension settings are correct.

You must set:

- **Auto Convert → OFF**  
- **Don’t prompt when reaching fallback installer → ON**

If you don’t see these options, update your Cyberpunk support extension to **v0.12.1**.

![Step 1](https://media.discordapp.net/attachments/1285796905640788030/1456238716745158740/image.png)

---

## ♦ Step 2 — Remove All Mods in Vortex

1. Open Vortex  
2. Go to **Mods**  
3. Press **CTRL + A** to select all mods  
4. Click **Remove**  
5. Select **Remove Mod**  
6. **Do NOT select “Delete Archive”**

If CTRL+A doesn’t work:

- Click the top mod  
- Scroll down  
- Hold **CTRL**  
- Click the last mod  

You may need to repeat this if older leftover mods appear.

> **Note:** If you have personal mods, write them down — you’ll need to reinstall them later.

![Step 2](https://cdn.discordapp.com/attachments/1324990321393930240/1457797741680791776/image.png)

---

## ❗ IMPORTANT — READ BEFORE STEP 3

Once all mods are removed:

# **VORTEX MUST BE CLOSED**

Do **not** leave it running in the background.  
If Vortex is open while running Mod Remover, it will cause errors later.

![Important](https://media.discordapp.net/attachments/1324990321393930240/1457843152437121035/image.png)
