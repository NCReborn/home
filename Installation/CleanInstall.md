🧼 Clean Install Guide — Cyberpunk 2077
This guide explains how to reset your modded Cyberpunk 2077 directory back to a clean state.
Use this when diagnosing issues such as:

Crashes

Redscript errors

Mod conflicts

Suspected broken installs

Problems after updating the collection

A clean install helps determine whether the issue is caused by the game, Vortex, or the collection.

♦ Step 1 — Check Your Vortex Cyberpunk 2077 Settings
Before doing anything, make sure your Vortex Cyberpunk extension settings are correct.

You must set:

Auto Convert → OFF

Don’t prompt when reaching fallback installer → ON

If you don’t see these options, update your Cyberpunk support extension to v0.12.1.

https://media.discordapp.net/attachments/1285796905640788030/1456238716745158740/image.png?ex=6a03067d&is=6a01b4fd&hm=7a2e9166f69b297fbd50ec0e344eeb3b1e4b42fbd91c8862b256c2846da56bbb&format=webp&quality=lossless&

♦ Step 2 — Remove All Mods in Vortex
Open Vortex

Go to Mods

Press CTRL + A to select all mods

Click Remove

In the popup, select Remove Mod

Do NOT select “Delete Archive”

If CTRL+A doesn’t work:

Click the top mod

Scroll down

Hold CTRL

Click the last mod

This highlights everything.

You may need to repeat this if older leftover mods appear.

Note: If you have personal mods, write them down — you’ll need to reinstall them later.

❗ IMPORTANT — READ BEFORE STEP 3
Once all mods are removed:

VORTEX MUST BE CLOSED.
Do not leave it running in the background.
If Vortex is open while running Mod Remover, it will cause errors later.

https://media.discordapp.net/attachments/1324990321393930240/1457843152437121035/image.png?ex=6a0396bc&is=6a02453c&hm=4ea9786e2f7ab33bb991dcc1769e707e97732cf307843726181da66b186af5ec&format=webp&quality=lossless&

♦ Step 3 — Download Mod Remover
Download the tool here:

🔗 https://www.nexusmods.com/cyberpunk2077/mods/8597 (nexusmods.com in Bing)

https://i.imgur.com/MQss7St.png

♦ Step 4 — Place Mod Remover in Your Game Root
Extract the contents of Mod Remover into your Cyberpunk 2077 root directory.

Then run either the .exe or .bat.

https://i.imgur.com/rPJZO76.png

♦ Step 5 — Run the Program
When you run Mod Remover:

Press Enter to create a backup

The tool will remove all modded files

It will show you where backups are stored

It will prompt you to verify your game files

https://i.imgur.com/OAtj8vO.png

♦ Step 6 — Verify Game Files
Open Steam or GOG and verify/repair your game installation.

https://i.imgur.com/sDpu3fo.png

♦ Step 7 — Final Checks
You now have a clean Cyberpunk installation.

Do NOT open Vortex yet.
Launch Cyberpunk normally (Steam/GOG)

Confirm it boots in a vanilla state

✔ Once confirmed:
Re‑add the collection from Nexus

Install it into a new Vortex profile

Do NOT reuse your old profile

This resolves most issues caused by:

Incorrect installs

Auto Convert being on

Old mod leftovers

Broken profiles

https://preview.redd.it/hxy0tun46p561.jpg?width=1080&crop=smart&auto=webp&s=0df95ead41a858e95991417a7485baab4b89ec16

⚠️ “Help, I got this message!”
If you see this error:

It means you did not follow the instructions correctly.
Start again from Step 1 and read carefully.

Hint:
You probably ignored the Vortex must be closed step.
